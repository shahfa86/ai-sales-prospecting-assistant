# Project Instructions

- Keep the app beginner-friendly so new Next.js and TypeScript developers can understand it quickly.
- Avoid external APIs, AI services, databases, or backend integrations unless the user explicitly requests them.
- Prefer simple TypeScript patterns and clear comments for important logic.
- Maintain clean component structure, readable styling, and descriptive names.
- Keep generated sales prospecting logic local and easy to edit unless a future task changes the architecture.
